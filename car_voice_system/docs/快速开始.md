# 车载语音系统 —— 快速启动步骤

---

## 一、Ubuntu 虚拟机端

```bash
# 1. 改时间（必须，否则 SDK 报 11212）
sudo date -s "20161215 14:12:10"

# 2. 清理旧进程和缓存
pkill -9 -f "./main"
rm -rf /mnt/hgfs/share/robot/x86/bin/msc
rm -rf /mnt/hgfs/share/robot/x86/bin/pcm/cmd.pcm
rm -f  /mnt/hgfs/share/robot/x86/bin/result.xml

# 3. 启动语音识别引擎
cd /mnt/hgfs/share/robot/x86/bin
./main
```

**看到 `wait for connecting ...` 就算就绪**，保持窗口开着，别关。

---

## 二、开发板端

```bash
# 1. 配置 IP 并检查网络
ifconfig eth0 192.168.5.3
ping 192.168.5.4

# 2. 清理旧进程（防止麦克风被占用）
pkill -9 car_voice
pkill -9 arecord

# 3. 下载最新程序
cd /
rm -f car_voice
tftp -g -r car_voice 192.168.5.2
chmod 777 car_voice

# 4. 加载 LED 驱动（已加载会报 File exists，忽略）
insmod /led_drv.ko

# 5. 启动程序
./car_voice 192.168.5.4
```

---

## 三、操作流程

```
1. 触摸 LCD 中央的【启动】按钮  → 串口打印 connected.
2. 按开发板串口终端的回车键      → 开始录音
3. 对着麦克风清晰说指令          → 等 1~2 秒
4. 屏幕切场景 + 显示语音回复
```

| 关闭车灯     | light_off.bmp + LED 灭 |

| 关闭空调     | ac.bmp                 |
| 空调升温     | ac.bmp，温度 +1        |
| 空调降温     | ac.bmp，温度 -1        |
| 打开车窗     | window.bmp             |
| 关闭车窗     | window.bmp             |
| 显示当前场景 | 保留画面               |

```bash
Ctrl+C
```

## 六、常见问题速查

| 现象                      | 一行修复                                           |
| ------------------------- | -------------------------------------------------- |
| `Connection refused`      | Ubuntu 端 `./main` 没启动                          |
| `构建语法失败 11212`      | `sudo date -s "20161215 14:12:10"` 后重启 `./main` |
| `Device or resource busy` | `pkill -9 car_voice; pkill -9 arecord`             |
| `Not started`             | Ubuntu 端 `pkill -9 -f "./main"` 后重启            |
| `Text file busy`          | `pkill -9 car_voice`                               |
| 识别置信度低              | 靠近麦克风、安静环境、说清楚                       |

## 七、一条龙复制版

**Ubuntu**（新建终端粘贴）：

```bash
sudo date -s "20161215 14:12:10" && \
pkill -9 -f "./main" ; \
rm -rf /mnt/hgfs/share/robot/x86/bin/msc /mnt/hgfs/share/robot/x86/bin/pcm/cmd.pcm /mnt/hgfs/share/robot/x86/bin/result.xml ; \
cd /mnt/hgfs/share/robot/x86/bin && ./main
```

**开发板**（串口粘贴）：

```bash
ifconfig eth0 192.168.5.3 ; \
pkill -9 car_voice ; pkill -9 arecord ; \
cd / && rm -f car_voice && \
tftp -g -r car_voice 192.168.5.2 && chmod 777 car_voice && \
insmod /led_drv.ko 2>/dev/null ; \
./car_voice 192.168.5.4
```
