# 车载语音控制系统（GEC6818）

## 一、项目简介
本项目基于 **GEC6818 ARM 开发板**，结合**离线语音识别引擎**（科大讯飞 SDK），实现一个**车载语音助手**。
用户通过语音指令即可控制车载场景，包括 **LED 车灯**、**空调**、**车窗**，并实时在
800×480 LCD 屏幕上显示对应的场景画面与人机交互对话。

项目架构为 **C/S 模式**：
- **服务端（Ubuntu）**：运行离线语音识别引擎，接收开发板上传的录音 PCM，返回识别结果（cmd id）。
- **客户端（GEC6818 开发板）**：负责录音、发送、接收指令、控制硬件、驱动 LCD 显示场景与对话。

## 二、功能要求对照

| 验收要求 | 本实现 |
|---|---|
| 对话内容 ≥ 5 段 | 实现 8 段人机交互对话（见第四节） |
| 语音控制 ≥ 3 场景 | 车灯(LED)、空调、车窗 三个场景 |
| LED 模拟一个场景 | 7/8 号 LED 模拟车载大灯，语音开/关联动点亮/熄灭 |
| 空调控制模拟(显示场景图) | 语音开/关/升温/降温，屏幕显示温度与状态 |
| 车窗控制模拟(显示场景图) | 语音开/关车窗，屏幕显示车窗场景 |
| 启动界面 | 开机显示项目标题与加载提示 |
| 语音控制主界面 | 显示全部语音指令列表 + "启动语音控制"触摸按钮 |
| 对话内容展示区 | 屏幕底部深色信息条，叠加显示助手回复文字 |
| 模拟场景显示区 | 各场景整屏切换显示 |
| 启动语音控制按钮 | 触摸屏点击按钮后进入语音识别循环 |

## 三、语音指令与场景映射
对应 `voice_engine/cmd.bnf` 语法文件：

| 语音指令 | cmd id | 触发场景 | 对话回复 |
|---|---|---|---|
| 你好 | 1 | 回到主界面 | 您好，我在呢！可以控制车灯、空调、车窗。 |
| 再见 | 2 | 退出程序 | 再见，祝您出行愉快！ |
| 打开车灯 | 10 | 车灯场景(LED 点亮) | 好的，已为您打开车载大灯。 |
| 关闭车灯 | 11 | 车灯场景(LED 熄灭) | 好的，已为您关闭车载大灯。 |
| 打开空调 | 20 | 空调场景 | 空调已为您打开，正在调节温度。 |
| 关闭空调 | 21 | 空调场景 | 好的，已为您关闭空调。 |
| 空调升温 | 22 | 空调场景(温度+1) | 空调已为您打开，正在调节温度。 |
| 空调降温 | 23 | 空调场景(温度-1) | 空调已为您打开，正在调节温度。 |
| 打开车窗 | 30 | 车窗场景 | 好的，已为您降下车窗。 |
| 关闭车窗 | 31 | 车窗场景 | 好的，已为您升起车窗。 |
| 显示当前场景 | 100 | 回到当前活动场景 | — |

## 四、8 段交互对话设计
1. 开机：**助手** → "您好，我是车载语音助手，请问需要什么帮助？"
2. 触摸启动语音：**助手** → "语音控制已启动，请说出指令..."
3. 用户"你好"：**助手** → "您好，我在呢！可以控制车灯、空调、车窗。"
4. 用户"打开车灯"：**助手** → "好的，已为您打开车载大灯。"
5. 用户"打开空调/降温"：**助手** → "空调已为您打开，正在调节温度。"
6. 用户"打开车窗"：**助手** → "好的，已为您降下车窗。"
7. 未识别：**助手** → "没有听清，请再说一遍。"
8. 用户"再见"：**助手** → "再见，祝您出行愉快！"

## 六、编译与部署

### 1. Ubuntu 端（语音识别引擎）
```bash
# ① 修改识别语法（可在 Windows 下编辑，注意 UTF-8 编码）
#    用 voice_engine/cmd.bnf 覆盖 x86 引擎的语法文件，然后重新编译引擎
cd /mnt/hgfs/share/robot/x86/examples/asr_record_demo
make clean
make

# ② 启动识别服务器（运行在 Ubuntu）
cd /mnt/hgfs/share/robot/x86/bin
./main
```
> 若提示错误码，需先将系统时间改为 2016 年（SDK 授权校验）：
> `sudo date -s "20161215 14:12:10"`
> 编译客户端时记得改回 2026 年，编译完再改回 2016 年运行。

### 2. 开发板端（客户端）
```bash
cd car_voice_system/src
make clean
make          # 生成 car_voice 可执行文件
```

### 3. 部署到开发板
```bash
# ① 下载可执行程序与字库
tftp -g -r car_voice 192.168.5.2
tftp -g -r simfang.ttf 192.168.5.2

# ② 下载 LED 驱动并加载
tftp -g -r led_drv.ko 192.168.5.2
insmod led_drv.ko

# ③ 若缺少动态库，将 lib/ 下 so 文件下载到开发板 /lib
tftp -g -r libjpeg.so.9 192.168.5.2   # 放入 /lib

# ④ 赋予权限并运行
chmod 777 car_voice
./car_voice 192.168.5.4        # 192.168.5.4 为 Ubuntu 服务器 IP
```

## 七、演示流程
1. 开机：屏幕显示"车载语音控制系统"启动界面。
2. 助手问候："您好，我是车载语音助手，请问需要什么帮助？"
3. 进入主界面，触摸"启动语音控制"按钮。
4. 终端提示按键 → 按回车 → 对着麦克风说"你好" → 屏幕回复对话。
5. 依次说出"打开车灯 / 打开空调 / 空调降温 / 打开车窗 / 关闭车窗 / 再见"，
   观察屏幕场景切换、LED 亮灭、对话更新。
6. 录制演示视频，覆盖全部 3 个场景与 ≥5 段对话。

## 八、常见问题
1. **字库加载失败**：确认开发板根目录有 `simfang.ttf` 且文件名完全一致。
2. **LED 无反应**：先 `insmod led_drv.ko` 加载驱动，设备节点为 `/dev/led_drv`。
3. **识别无返回**：确保 Ubuntu 服务器 `./main` 在运行、IP 正确、网络可 ping 通。
4. **中文乱码**：源码与 cmd.bnf 必须为 UTF-8 编码。
5. **重启后失效**：GEC6818 为 RAM 文件系统，断电/重启后驱动、程序、字库需重传。
